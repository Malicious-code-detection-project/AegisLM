# 이정민 개인 하네스

이 프로필의 현재 포맷은 [`harness/README.md`](harness/README.md)에서 시작한다.

## 세션 진입

1. 저장소 루트의 `AGENTS.md`와 작업 경로에 적용되는 팀 규칙을 먼저 확인한다.
2. 루트의 `.active-profile`이 `jeongmin`인지 확인한다. 이 값은 ASCII 프로필 식별자이며, 이 폴더의 표시 이름은 `이정민`이다.
3. 새 세션은 `harness/README.md`, `harness/core/principles.md`, 현재 역할 문서, 현재 과업만 읽는다.
4. 위임·고영향 작업·기록 확장이 필요할 때만 `harness/core/workflow.md`를 추가한다.

## 포맷 전환

이전 포맷 자료는 이번 전환에서 제거하고 새 하네스만 유지한다. 운영 규칙은 두 포맷에서 동시에 읽지 않고 새 하네스의 문서를 기준으로 한다. 기존 과업·Wiki·원자료를 새 양식으로 일괄 변환하지 않는다.

실행 설정과 세션 산출물은 루트의 `.harness-local/jeongmin/`에 둔다. API 키, 토큰, 모델 산출물은 이 저장소에 기록하지 않는다.
