# 실행 연결 — 최초 적용·플랫폼 변경 때만

이 문서는 연결 기준이다. 등록 파일·설치 명령·설정 생성기를 제공하지 않는다. `references/이정민/`의 Markdown은 도구에 자동 등록되지 않는다. 현재 프로그램의 허용된 에이전트 생성 화면/설정에서 본문과 필요한 공통 지침을 전달하거나 수동 세션으로 사용한다.

## 공개 방식과 우리 적용

| 환경 | 공개 문서에서 확인한 연결 | 우리 적용 |
| --- | --- | --- |
| Codex | 사용자 지정 에이전트의 모델·추론·지침·샌드박스 설정, 별도 TOML 등록 | 현재 세션은 메인, 다섯 역할은 필요할 때만 별도 세션. 이 묶음이 등록을 수행하지 않음 |
| OpenCode | 주/하위 에이전트, Markdown 정의, `provider/model-id`, 역할별 permission | 같은 역할 본문을 사용하고 모델·권한은 해당 앱에서 설정 |
| Pi subagent 예제 | Markdown 에이전트 + 확장 코드, 역할별 model/tools, 별도 프로세스 | 이미 설치된 신뢰할 수 있는 확장이 있을 때 연결; Markdown만으로 확장이 생기지 않음 |
| Oh My Pi | 작업별 모델 슬롯·하위 작업·별도 advisor | 필요한 슬롯/작업만 사용. 매 턴 advisor는 기본에 넣지 않음 |
| Claude Code | Markdown 사용자 지정 에이전트와 모델/도구 설정 | Claude 프로필로 대응. GPT ID를 적는 것만으로 GPT가 연결된다고 가정하지 않음 |

출처: [Codex](https://developers.openai.com/codex/subagents/), [OpenCode](https://opencode.ai/docs/agents/), [Pi](https://raw.githubusercontent.com/badlogic/pi-mono/main/packages/coding-agent/examples/extensions/subagent/README.md), [OMP](https://github.com/can1357/oh-my-pi), [Claude Code](https://code.claude.com/docs/en/sub-agents). 2026-09-30 조회; 설치된 버전에 따라 다르다. 사용자 계정에서의 실행은 미확인이다.

## 기능을 도구에 매핑

`done`은 결과 반환, `read`는 원본 조회, `bash`는 허용 명령 실행, `write/apply_patch`는 범위 내 변경, `term`은 필요할 때의 프로세스 제어라는 **의미**로 대응한다. 실제 이름·인자·가능 여부는 앱 정의를 따른다. 도구명을 프롬프트에 적어 새 도구를 만들지 않는다.

explorer/planner/reviewer: 원본 읽기·검색만. 셸을 주면 명령 제한·샌드박스가 함께 필요하다. tester-verify: 원본 읽기 + 격리 실행 + 지정된 캐시/출력 경로만 쓰기. patcher/tester-repair: 승인 경로에만 쓰기. 임의 셸 실행이 가능한데 도구 목록만으로 완전한 읽기 전용이라고 표시하지 않는다.

## 첫 연결 확인

1. 실제 앱/버전·모델 목록·계정 접근·공식 인증 경로와 데이터 전송 범위를 확인한다. 구독을 타사에 자동 전용하거나 토큰을 복사하지 않는다.
2. 모델 ID와 지원 API·추론 설정·도구 스키마를 맞춘다. Sol 6.1 도구 호출은 Responses API를 사용한다. 채팅 텍스트 응답만 성공한 것은 에이전트 연결 성공이 아니다.
3. 비민감 임시 fixture에서 파일 읽기 → 도구 결과 반환 → 모델 후속 응답의 왕복을 시험한다. 쓰기 역할은 승인된 임시 파일 변경/검증, 읽기 역할은 같은 임시 쓰기의 차단 또는 제한 상태를 확인한다. 실제 코드/악성 파일로 시험하지 않는다.
4. 요청 모델과 실행 모델을 런타임 표시·로그에서 대조한다. 부모 모델/추론값 상속·전역 강제값·숨은 대체를 확인한다. 알 수 없으면 미확인으로 기록하고 중요한 결과 검증에 사용하지 않는다.

이 연결 시험은 [역할 성능 시험](../EVALUATION.md)을 대신하지 않는다. 새 제공자·권한·도구·모델 버전으로 바뀌면 영향받는 시험만 반복한다. 원본 작업을 연결 시험 때문에 변경하지 않는다.

## 실행 불가 시

하위 호출 기능이 없으면 별도 수동 세션에 패킷을 전달한다. 한 세션의 관점 전환은 자기 검토라고 명시한다. 필요한 독립 검토를 흉내 내지 않는다. 허용된 대체 모델이 없다면 부분 결과·연결 공백을 보고하고, 인증/정책 우회나 무단 외부 전송을 하지 않는다.
