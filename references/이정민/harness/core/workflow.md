# 운영 절차 — 위임·중요 작업·기록 확장 시

공통 기준은 [principles.md](principles.md)다. 아래는 추가 상황에만 적용한다.

## 1. 실행과 검증을 함께 설계

기록이 필요한 새 과업의 기준 파일은 `task.md`다. 목표·성공 기준·가정·범위를 정하고 결과를 판별할 최소 작업을 고른다. 자료로 풀리는 질문은 먼저 확인하고, 이미 합의된 내용은 다시 승인받지 않는다. 결과·안전에 큰 영향을 주는 미정 사항만 사용자에게 확인한다.

연구·고비용 실험은 실행 전에 질문/가설, 비교 대상, 데이터 중복·분할·누수, 지표·실패 출력 처리, 최종 평가 보호, 재현 조건·변동성 처리와 자원 상한을 확인한다. 결과 이후에는 관측과 대안 설명을 구분한다. 핵심 연구 결론·광범위 변경은 적합한 사전 검토와 결과 검토를 배치한다. 작은 수정에도 관련 테스트 등 성공 근거는 필요하다.

검토자는 작성 참여 여부를 밝힌다. Sol이 설계에 참여했다면 그 부분은 독립 검토 대상에서 빠지며 다른 적합한 검토자를 정하거나 검토 공백을 남긴다. 판단 충돌은 최소 원본 확인·테스트로 좁히고 다수결이나 직함으로 통과시키지 않는다.

## 2. 필요한 역할에 한 번 전달

자료가 충분한 작은 작업은 Astra가 직접 처리한다. 분리할 이익이 있는 조사·구현·반복 실행만 맡긴다. 독립된 파일·입력·자원을 쓰는 작업만 병렬화한다.

```text
작업/역할/모드:
기여할 성공 기준 + 답할 질문:
필수 입력·원본·이미 확인한 근거와 적용 조건:
기대 산출물 + 검증 방법:
수정 경로·자원·승인 범위·중단 조건:
선행 작업·편집 담당·반환 대상:
```

새 전문 세션에는 `core/principles.md`와 자기 역할 문서, 위 패킷만 기본 전달한다. 목적·현재 결정·권한이 빠졌으면 과업 기록의 해당 절을 추가로 읽는다. 전체 대화나 무관한 과거 과업은 넘기지 않는다. 패킷은 과업 기록의 전달용 사본이며 별도 원장으로 갱신하지 않는다.

실제 전달 수단이 없으면 패킷 초안 또는 자기 수행으로 구분한다. 독립 검토가 필요한 과업을 자기 수행으로 바꾸어 검증 공백을 숨기지 않는다.

## 3. 결과 회수와 부분 보완

```text
작업 상태: 완료 / 부분 완료 / 보류
실제 수행·산출물·변경 범위:
근거: 원본 위치·실행 여부·방법·결과·적용 조건
미검증·결함·다음 최소 행동:
```

Astra가 결과를 성공 기준에 연결한다. 구현 결함은 Terra, 실행 조건·누락은 Luna, 가설·방법론 문제는 Astra/Sol의 해당 작업으로 돌린다. 전체 계획을 다시 쓰기 전에 부분 수정으로 해결 가능한지 판단한다. 이미 유효한 근거는 재사용하고 바뀐 후보·조건에 대해서만 필요한 검증을 한다.

## 4. 기록은 필요할 때만 분리

단순 질의는 대화, 기록이 필요한 보통 과업은 `task.md` 하나를 사용한다. 긴 계획이 현재 행동을 가리면 `plan.md`, 근거가 길어 원본 추적을 방해하면 `evidence.md`, 별도 제출물이 필요하면 `result.md`만 만든다. 파일 수를 맞추려고 분리하지 않는다.

분리한 항목의 본문은 해당 파일을 유일 기준으로 삼고 `task.md`에는 링크와 재개에 필요한 요약만 둔다. 성공 기준·현재 상태는 `task.md`에 유지한다. 분리 전 본문을 두 곳에서 계속 갱신하지 않는다. 전체 대화 대신 결정 이유·현재 문제·다음 행동을 남긴다.

기존 `brief/plan/state/evidence/result.md` 과업은 기존 기준을 유지한다. `task.md`를 추가하지 않고 `brief.md + state.md`에서 재개한다. 형식을 바꾸려면 별도 합의 후 단일 기준 문서를 명시한다.

## 5. 종료·지식 반영

성공 기준의 판정, 실제 산출물, 한계와 다음 행동을 보고한다. 재사용할 내용이 있고 쓰기 범위가 허용된 경우만 [지식 운영 절차](../playbooks/llm-wiki.md)로 반영한다. 없으면 기록도 추가하지 않는다. 큰 Wiki 정비는 별도 과업이다.

재개 시 현재 기록과 다음 행동에 필요한 근거만 확인한다. 대화만으로 끝내던 작업도 중단·인계가 필요해지면 최소 상태를 남긴다.
