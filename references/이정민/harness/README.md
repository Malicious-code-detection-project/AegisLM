# 과업 성공 중심 하네스 v3.0

목표: 필요한 전문성과 기존 지식을 연결해 **합의한 과업을 실제 근거로 완료**한다. 문서·호출 수를 성과로 삼지 않는다.

## 시작

새 세션은 이 문서 → [공통 원칙](core/principles.md) → 자기 역할 → 현재 과업만 읽는다. 기본 헤드는 [Astra](roles/astra.md)다. 같은 세션의 현재 맥락에 남아 유효한 지침은 재주입하지 않는다.

| 필요한 기여 | 역할 |
| --- | --- |
| 질문·계획·통합·최종 판단 | [Astra](roles/astra.md) |
| 조사·대안·방법론·독립 검토 | [Sol](roles/sol.md) |
| 구현·테스트·디버깅 | [Terra](roles/terra.md) |
| 실행·측정·재현 기록 | [Luna](roles/luna.md) |

짧은 질의는 대화에서 끝낸다. 기록이 필요한 **새 과업**은 [task.md](tasks/_template/task.md) 하나만 `tasks/<과업명>/task.md`로 복사한다. 기존 과업의 `brief.md + state.md` 등은 그대로 재개하며 새 양식으로 다시 쓰지 않는다.

위임·병렬 작업·고비용/고영향 작업·기록 분리가 필요할 때만 [운영 절차](core/workflow.md)를 읽는다. 기존 지식이 필요하면 [Wiki 인덱스](../wiki/index.md)에서 관련 페이지만 읽는다. Wiki를 수정할 때만 [지식 운영 절차](playbooks/llm-wiki.md)를 읽는다. 원문·전환 안내는 기본 입력이 아니다.

## 첫 입력 예시

```text
references/이정민/harness/README.md를 진입점으로 Astra 역할을 수행하라.
과업: [실제 요청]
현재 과업 경로: [기존 경로 또는 새 과업]
허용 범위·환경·자원: [실제 조건]
Wiki 범위: [읽기 / 후보 제안 / 지정 범위 반영]
필요한 지침만 읽고 허용 범위에서 수행·검증까지 진행하라.
```

폴더 배치만으로 모델 연결·자동 로딩·권한 통제가 생기지 않는다. 파일 접근이 없으면 필요한 문서를 전달하고, 별도 호출이 없으면 역할 전환을 독립 에이전트 실행으로 표시하지 않는다. 실제 모델·세션은 실행 환경에서 확인한다.

설치기·실행 설정·루트/전역 변경은 포함하지 않는다. 최초 적용·경로 전환·측정 결과는 [REFACTOR.md](REFACTOR.md)에서 확인한다.
