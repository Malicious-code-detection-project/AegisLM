# 지식 운영 — 조회·반영·정정의 단일 절차

공통 신뢰·권한 기준은 [principles.md](../core/principles.md)를 따른다. 조사·구현 역할은 근거를 반환하고, 실제 Wiki 편집자만 이 문서를 읽는다. 기본 편집자는 Astra이며 다른 과업과도 같은 파일의 편집 순서를 맞춘다.

## 조회: 새 결정을 돕는 만큼만

[인덱스](../../wiki/index.md) → 관련 페이지 → 중요한 주장의 원자료·조건 순서로 확인한다. 이미 직접 제공된 페이지가 있으면 검색을 반복하지 않는다. 없으면 원자료 조사로 넘어가며 Wiki를 먼저 채우지 않는다. 읽기만 한 사건은 로그에 남기지 않는다.

`draft`·`deprecated`, 버전 변경, 상충 근거는 재확인 신호다. `stable`이나 최근 작성일만으로 진실·최신성을 보장하지 않는다. 적용할 수 있는 기존 근거와 이번에 확인해야 하는 부분을 나누어 사용한다.

## 반영: 재사용할 변화가 있을 때만

1. 관련 기존 페이지와 원본을 확인한다. 이미 담긴 동일 정보라면 수정·로그·새 문서를 생략한다.
2. 편집이 허용됐고 재사용 가치가 있을 때 기존 페이지를 갱신한다. 없을 때만 [페이지 틀](../templates/wiki-page.md)을 적절한 주제 폴더에 복사한다.
3. 주장, 출처, 적용 조건, 확인 방법·범위와 한계를 남긴다. 원자료나 전체 과업을 복사하지 않는다. 과업 근거는 과업 경로와 근거 ID를 함께 연결한다.
4. 새 페이지·이동·제목·설명이 바뀐 경우에만 인덱스를 고친다. 의미 있는 지식 변경은 `wiki/log.md`의 실제 날짜 아래 한 항목으로 묶는다. 오탈자·서식만 바꾸면 기록을 강제하지 않는다.
5. 실제 반영과 제안을 구분해 과업에 한 줄만 남긴다. 중단됐다면 바뀐 파일과 남은 인덱스/링크 작업을 기록한다.

Wiki 전체 정비를 현재 과업에 자동 추가하지 않는다. 전체 과업이 부분 완료여도 독립적으로 유효한 발견은 한계와 함께 남길 수 있다. 예상되는 미래 효용만으로 근거 없는 페이지를 만들지 않는다.

## 표현: OKF는 지식 파일에만

우리 대상은 **OKF 0.2**다. Wiki의 `index.md`, `log.md`를 제외한 `.md`에 YAML frontmatter를 사용한다. 공식 필수 키는 `type`이며 나머지 신뢰·수명 필드는 선택이다. 우리 작성 기본값은 `type`, `title`, `description`, `status: draft`이고, 사실 주장은 실제 `sources`와 연결한다. 이는 개인 운영 기준을 더한 것이다. 공식 근거·예외는 [OKF 자료](../../wiki/sources/google-open-knowledge-format.md)에 있다.

출처는 `sources: [{id, resource}]`, 주장 연결은 같은 ID의 각주를 사용한다. 본문은 `주장/유형 → 조건 → 확인 방법·시점 또는 미확인 → 한계`면 충분하다. 같은 검토 상태를 인덱스·확장 필드·본문 표로 따로 관리하지 않는다.

`generated`, `verified`, `stale_after`는 실제 작성·확인 사건·기한이 있을 때만 쓴다. 시간 값에는 시간대를 포함하고, 사람 승인이나 별도 모델 호출을 만들어내지 않는다. 형식 검사만으로 `verified`를 추가하지 않는다. 일부 주장만 확인했다면 본문에 그 범위만 적는다. 기존 유효 메타데이터·알 수 없는 확장 필드는 축약을 이유로 지우지 않는다.

`stable` 전환은 명시한 확인 범위를 충족했을 때만 한다. 내용 변경으로 이전 확인이 적용되지 않으면 해당 사건을 현행 검증으로 사용하지 않고 기존 이력·로그에 범위를 보존한다. `status`는 수명 상태이지 진실 점수가 아니다.

## 정정: 영향받은 주장부터

조건 차이와 반증을 구분한다. 해결되지 않은 핵심 충돌은 본문에 양쪽 근거를 남기고 `draft`로 사용 주의를 표시한다. 폐기·대체는 `deprecated`와 후속 문서를 연결한다. 중요한 정정은 인용한 페이지까지 필요한 범위를 점검하고 이유를 기록한다. 단순 반영에서 전체 Wiki 린트를 수행하지 않는다.

동시 수정 충돌은 최신 파일을 다시 읽어 조정한다. Markdown 규약은 잠금·트랜잭션·백업을 제공하지 않는다. Git 이력이나 사본이 없는데 복구 가능하다고 가정하지 않는다.

## 경로와 보존

템플릿은 내용 틀만 포함하며 `../schema.md` 같은 고정 내부 링크를 담지 않는다. 출처와 관련 링크는 **복사한 목적지 기준**으로 만든 뒤 존재를 확인한다. `/`로 시작하는 OKF 경로는 Wiki 루트 기준이나 일반 편집기의 해석은 다를 수 있어 상대 링크를 기본으로 쓴다.

원자료는 승인된 기존 위치 또는 `raw/`에 보존한다. 공개 원문·민감 자료를 임의 재배포하지 않는다. `wiki/` 밖 출처가 있으므로 전체 참조를 옮길 때는 `references/이정민/`와 외부 의존을 함께 확인한다. 도구 도입·외부 업로드·자동 실행은 이 절차의 일부가 아니다.
