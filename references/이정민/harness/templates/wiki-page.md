# [실제 제목]

> 작성 틀이다. `sources`에는 실제 출처의 `id`와 `resource`를 넣고, 아래 주장에 같은 ID의 각주를 연결한 뒤 이 안내를 지운다. 빈 출처로 외부 사실을 확정하지 않는다. 원문·버전·실행 정보는 확인한 값만 쓴다.

## 핵심 내용

[출처 주장 / 직접 관측 / 해석·가설 / 결정·제안] — [재사용할 내용]

## 적용 조건과 확인 범위

대상·버전·환경: [해석에 필요한 조건]
확인 방법·시점·원문 위치: [실제 확인 또는 미확인]
한계·상충·재확인 조건: [해당 내용]

> 선택 항목은 필요할 때만 추가한다. 출처·관련 페이지의 링크는 최종 저장 위치를 기준으로 만든다. 이 틀에는 복사 위치에 종속된 내부 링크가 없다.
