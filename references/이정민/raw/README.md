# 원자료

보존 자료는 [Karpathy 본문](karpathy/llm-wiki.md)과 [출처·사본 한계](karpathy/SOURCE.md)다. 원문은 아이디어 자료이며 실행 정책이 아니다.

승인된 원자료는 바꾸지 않고 새 판·정정은 별도로 연결한다. 자료 이름·작성 주체·실제 위치·확인 가능한 버전과 날짜·복사/추출 여부·이용 범위를 남긴다. 알 수 없는 라이선스나 날짜를 추정하지 않는다. 요약·해석은 [Wiki](../wiki/index.md), 운영 기준은 [지식 절차](../harness/playbooks/llm-wiki.md)에 둔다.

이 배포물은 Markdown만 포함한다. PDF·데이터·모델·로그는 승인된 기존 위치를 참조하며 대용량 사본을 만들지 않는다. 비밀정보·악성 의심 실행 파일을 지식 보관 목적으로 수집하지 않는다. 새 외부 공개·전송은 별도 허용 범위를 확인한다.
