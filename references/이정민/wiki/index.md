# 재사용 지식

현재는 하네스 설계 참고 지식만 있다. 실제 B200·vLLM·데이터셋 실험값은 입력하지 않았다. 관련 지식이 없으면 원자료 조사로 넘어간다.

## 하네스 설계 참고

- [Karpathy LLM Wiki — 출처 요약](sources/karpathy-llm-wiki.md) — 원자료와 연결된 지식을 분리하고 조회·반영·점검하는 아이디어.
- [OKF 0.2 — 최소 표현과 확인 경계](sources/google-open-knowledge-format.md) — 공식 필수 필드와 선택 신뢰 정보를 개인 Wiki 운영 기준과 구분.
- [과업 성공 중심 통합 구조](decisions/harness-wiki-integration.md) — 역할·기록·지식의 중복을 줄이고 필요한 때만 확장하는 설계 결정.

메타데이터·본문의 확인 범위는 해당 페이지를 기준으로 한다. 상태를 이 목록에 복사하지 않는다. 운영 규칙·템플릿은 검색할 지식 페이지가 아니다.
