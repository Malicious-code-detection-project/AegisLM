# Jeongmin · Selected References

현재 활성화된 동료 자료는 **없음**. 팀원 실제 파일을 아직 제공받지 않았으므로 임의로 등록하지 않았다.
등록 형식과 처리 규칙은 [team-references](harness/team-references.md)를 따른다.
기계 점검 대상 목록은 [references.registry.json](references.registry.json)이다.

| ID | 원본 경로 | 적용 조건/단계 | 상태 | 버전/hash | 내 적용 메모 |
|---|---|---|---|---|---|

이 표는 사람이 읽기 위한 색인이다. 등록을 추가할 때 JSON 목록도 함께 갱신한다.
다른 팀원의 전체 하네스보다 특정 규칙/공식/체크리스트 한 파일을 연결한다.
정본의 내용을 변경할 권한은 소유자/팀 정책에 따른다.
