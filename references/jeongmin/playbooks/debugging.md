# Playbook · Debugging

조건: 예외·실패 테스트·성능 회귀·환경 차이.

Luna: 실제 오류, 버전, cwd, 입력, 재현 명령, 발생 파일/심볼, 최근 변경 범위를 수집한다.
'아마 캐시 문제'를 사실로 단정하지 않는다. 환경 문제와 구현 결함을 분리한다.

Sol: 가장 작은 재현과 가설을 정하고 테스트로 반증 가능한 형태로 좁힌다.
Terra: 승인된 범위에서 원인을 수정하고 해당 버그의 회귀 테스트를 작성한다.
Luna: 수정 전후의 같은 입력/환경을 비교한다. 서로 다른 후보의 결과를 섞지 않는다.

동일 원인 수정이 두 번 실패하거나 동시성/보안/프로토콜 문제면 Sol이 Astra로 승격한다.
권한 부족이나 모델 사용 제한은 더 강한 모델로 우회하지 않는다.
결과: 관측 사실, 근본원인과 그 근거, 수정, 실행 검증, 남은 불확실성.
